# RideShare Mobile

Projekt Next.js për ushtrimin e Javës 3: lista e udhëtimeve, faqja e
detajeve dhe kërkesa e simuluar për një vend.

## Nisja lokale

```bash
cd aplikacioni
npm install
npm run dev
```

Pastaj hap [http://localhost:3000](http://localhost:3000).
